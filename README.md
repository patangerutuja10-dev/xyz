DIGITAL LIBRARY WEBSITE — GITHUB PAGES READY

This is a self-contained static frontend that runs on GitHub Pages without Node.js, a database, or a backend.
Features:
- Responsive dashboard
- Book catalogue with search and category filter
- Recommendations
- Create and track procurement requests
- Requests saved in this browser using localStorage

PUBLISH THIS SITE:
1. Download and extract this ZIP.
2. Open your GitHub repository.
3. Upload index.html, style.css, script.js, and README.md from this folder to the REPOSITORY ROOT (not inside another folder).
4. Commit changes to the main branch.
5. Open Settings > Pages.
6. Under Build and deployment, select "Deploy from a branch".
7. Choose Branch: main and Folder: /(root), then Save.
8. Wait a minute and open the Pages URL shown in Settings > Pages.

IMPORTANT:
- Do not upload the ZIP itself expecting GitHub to extract it; upload the extracted files.
- This version is a functional frontend/demo. It saves requests in the current browser only. Real shared login, persistent database, and backend procurement workflow need a hosted backend and database.
